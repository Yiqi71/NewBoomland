# NewBoomland

基于 BoomLand V2.6 和已核对 IA 的可交互前端原型。使用普通 HTML、CSS、JavaScript，无需 npm、Node.js 或构建步骤。

## 打开

- 推荐：双击 `启动预览.command`，在浏览器打开 `http://127.0.0.1:4321`。
- 也可直接打开 `index.html`。浏览器对本地文件的数据保存限制可能不同，建议使用本地预览。
- 在终端运行：`python3 serve.py`。结束预览时按 Control-C。

## 看什么

右下角「预览设置」可以切换访客、参赛者、主办方、评委、企业和平台管理员，也可切换赛季阶段、报名窗口及列表的加载/空/失败状态。页脚「页面总览」可访问全部 40 个 IA 页面和子视图；侧栏保留主要入口，子视图由页面内操作进入。

现有 Figma 用作视觉方向参考，优先完成页面结构与流程，并非所有页面逐像素定稿。横幅及相关图标来自用户指定 Figma 的原始素材，已经下载到 assets，不依赖临时链接。

## 可验证的演示流程

1. 将报名窗口设为「报名中」，以访客身份提交个人报名。
2. 切换主办方，在「报名与拉群」审核刚提交的申请，并记录微信群状态。
3. 切回参赛者，在进行中赛季新建项目，选择可用命题，然后发布作品。
4. 切换评委，对其他项目作品评分。本人参与项目需要回避；同一版本不允许重复赋分。
5. 切换主办方或管理员，查看更新的积分、待复核评分和操作记录。
6. 管理员可冲正错误评分，原记录保留，积分与预计奖金同步减少。
7. 进入结算中后无法新增作品或评分；存在待复核评分或未解决异议时不能定格。

数据保存在当前浏览器的 localStorage；刷新可保留。「重置演示数据」只清除此原型的本机模拟记录。

## 范围与限制

- 这是模拟数据原型，没有后端、真实账号、服务端权限、实际支付、邮件、微信或短信接口。
- 文件选择只记录文件名，不上传、不保存文件内容；不能用来收集真实私密凭证。
- 预览身份切换是评审工具，不是安全边界；所有真实权限仍需后端实现。
- 原型在配置的阶段下模拟截止行为，不把现实系统时间误当作虚拟赛季时间。实际日期自动切换、定时任务与提醒未实现。
- 作品首次发布、评分、复核、冲正等关键流程可操作；完整的作品增量版本编辑、成员邀请/转让、企业命题五件套发布编辑器尚未完成。相应视图提供内容结构或明确说明，没有伪造成功发布。
- 商业结果仅演示提交和管理员核验，不做真实合同/交易去重或财务验证。
- `docs/ia.json` 保存本次读取的 40 张 IA 卡片；它是页面内容依据，不代表 40 个独立网页 URL 的最终产品决策。
- `docs/decisions.md` 说明未定业务规则与采用的原型边界。

## 文件

`index.html` 页面入口；`styles.css` 通用样式与响应式布局；`data.js` 路由与模拟数据；`app.js` 通用组件与渲染；`views.js` 各页面内容；`interactions.js` 表单及交互；`serve.py` 本地预览。

本地预览默认只监听 127.0.0.1，不对外部署。

## 参赛者页面与演示数据

打开「预览设置 → 参赛者演示场景」，选择「已有项目 · 滚动评分」即可查看完整工作台。也可从参赛者工作台的「切换演示场景」查看审核中、候补、待开赛、待组队、作品截止、结算、定格、归档、暂停和取消，共 11 种状态。场景会替换当前赛季的本机模拟记录，其他赛季保留；不会自动覆盖正在填写的真实原型报名流程。

示例项目「创作者合作手账」包含 3 件作品，累计 380 分；两位评委对同一访谈作品分别赋分 120 与 80，原型作品 180 分待复核。演示兑换比例为每积分 1.5 元，预计奖励 570 元，阶段认证与商业结果另行记录。演示日期为模拟赛程。

参赛者赛季详情优先展示个人项目、下一步、作品评分与相关公告，公共命题、规则和榜单可展开浏览。工作台侧栏收敛为我的赛季、我的项目、我的奖励与记录，发布入口随阶段切换。`participant.js` 集中维护参赛者视图与显式载入的演示场景。
