# 业务待确认与原型处理

依据：BoomLand 产品需求文档 V2.6 第 0.0、4、5、7、9.9、14、16 章，以及 Figma 中已核对的 IA（352:641）。

这份原型用于确认页面架构和操作关系。规则建议不等于已批准的产品决定。

## 原文冲突

1. **报名与开赛时间**：5.0 要求报名截止早于开赛，9.9 允许开赛后仍在报名窗口。本原型将报名窗口与赛季阶段分开预览；配置表不擅自锁定两者关系。
2. **成员管理**：待定 10 把成员增删和发起人转让列为 P1，其他流程又依赖它。原型不实现真实邀请或转让，不能把文本登记当作成员接受邀请。
3. **复核驳回与冲正**：4.3/4.5/REV-006 只允许管理员冲正，待定 13 拟允许主办方以另一类型执行复核驳回。原型将主办方的异议转交管理员，不自行扣分；普通冲正仅管理员可执行。

## 21 项待定的落地边界

| 编号 | 议题 | 原型处理 |
|---|---|---|
| 1 | 单次上限如何结合命题 | 演示赛季级上限；未擅自新增命题级计算公式 |
| 2 | 同版本与跨版本累计限制 | 实现同评委同版本去重，未实现待定倍数阈值与增量编辑 |
| 3 | 企业范围与作品标注 | 报告保守地只展示标注本企业命题且公开的作品；不展示任何私密材料 |
| 4 | 积分池与预算对齐 | 追加时按文档建议要求有预算支持，并提示该规则属于建议 |
| 5 | 驳回与重大变更重审 | 演示发布批准与驳回，不自动代替实际重大规则重审批流程 |
| 6 | 定格后何时归档 | 通过预览设置查看两种状态，不自动在三十天后归档 |
| 7 | 暂停、缩短与过期截止 | 暂停阻止操作；不实现未确定的四十八小时和过期时间变更规则 |
| 8 | 多组织与发奖主体 | 演示一个发奖主体、同季组织；组织争议由管理员处理 |
| 9 | 个人事件定向通知 | 演示公共公告和未读红点，未实现真实定向消息投递 |
| 10 | 成员确认与变更 | 仅演示登记与资格校验，未实现接受邀请、增删和转让 |
| 11 | 长期层优先级 | 只提供最小项目和人才浏览入口，不扩展全站功能 |
| 12 | 开赛与发布门槛 | 九项检查和手动开赛；没有后台定时提醒 |
| 13 | 回收、冲正退回、复核驳回 | 不自动回收所有未用额度；冲正减少有效用量、保留原额度分配；主办方转交管理员 |
| 14 | 名额与候补 | 展示候补状态，不实现递补时限和自动递补 |
| 15 | 撤回与退出 | 演示审核前撤回，不实现依赖成员转让的退赛流程 |
| 16 | 评委公示 | 未公开评委额度或联系方式；管理台中的数据不等于公开信息 |
| 17 | 编号、形式、不计分赛季 | 默认只演示计分常规赛季，不启用发布门槛豁免 |
| 18 | 异议窗口 | 演示状态流转，不擅自限制为七天 |
| 19 | 排名奖金 | 不设置额外排名奖金 |
| 20 | 同项目并行赛季 | 本原型只对一个主赛季写入，不模拟跨季并行结算 |
| 21 | 项目总积分上限 | 不添加项目总上限，受评委额度、积分池与预算约束 |

## 状态覆盖

- 赛季：即将开始、进行中、作品截止后评分仍开放、结算中、已定格、已归档、已暂停、已取消。
- 报名：未开放、报名中、已截止；申请有审核中、已通过、候补、未通过、已撤回。
- 列表：正常、加载、空、失败；权限不匹配时显示无权限界面。
- 金额：预计、已核定、已发放、取消；真实的部分发放与财务对账尚未接入。
- 小屏：360px、768px，以及桌面布局；需在生产实现时继续进行辅助技术与真实设备验收。
